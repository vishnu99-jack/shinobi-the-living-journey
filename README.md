# SHINOBI — The Living Journey

A static browser game built with HTML, CSS, vanilla JavaScript and Canvas. No build step, backend, or external assets are required.

## Story Journey

Open `index.html` in a modern browser or publish the repository root with GitHub Pages.

- **WASD / Arrow Keys:** move
- **E / Space:** interact
- **Touch:** use the directional pad and nearby action prompt

Create a shinobi, meet the village, and investigate the D-rank mission **The Missing Supplies**. Story progress is stored in this browser with localStorage.

## Endless Journey

- **Space / Up:** jump
- **Down:** slide
- **P:** pause or resume
- **R:** restart

Chakra adds 25 points and scrolls add 100. Runner best score is stored separately in localStorage.

## GitHub Pages

Publish from the `main` branch and repository root in **Settings → Pages**.

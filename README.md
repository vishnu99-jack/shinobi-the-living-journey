# SHINOBI — The Living Journey

A small, browser-based endless runner made with HTML, CSS, vanilla JavaScript and Canvas. No build step or backend is required.

## Play

Open `index.html` in a modern browser, or publish the repository root with GitHub Pages.

- **Space / Up:** jump
- **Down:** slide
- **P:** pause or resume
- **R:** restart
- **Touch:** tap to jump, swipe down to slide

Chakra adds 25 points; scrolls add 100. Best score is saved in this browser using localStorage.

## GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The site URL appears on the Pages settings screen after publishing.
